## Why

The portfolio website currently has a solid dark background color. Adding a grid pattern background will create a modern, high-tech, and visually engaging experience for visitors, aligning with the neon aesthetic (cyan/pink) of the site.

## What Changes

- Add a responsive, subtle CSS-based grid pattern background covering the entire website.
- Ensure the background integrates smoothly with the existing `--color-mViolet` (dark violet theme) without reducing text readability or contrast.
- Ensure the background adjusts gracefully to different screen sizes.

## Capabilities

### New Capabilities
- `theme-background`: Style and display a responsive, high-fidelity grid background pattern on all pages.

### Modified Capabilities
<!-- None -->

## Impact

- `src/index.css`: To define the CSS background pattern variables and rules.
- `src/App.jsx`: To apply the background container wrapper.
